# Temple of Elemental Evil 한국어화

**Temple of Elemental Evil (TOEE) 한국어화 프로젝트**입니다.

현재 공개 범위에는 게임의 로딩/엔딩 슬라이드 이미지 한국어화가 포함됩니다.

## 슬라이드 한국어화

- 대상 이미지: 116장
- 해상도: 800×500
- 형식: JPEG
- 원본 파일명 유지
- 로딩/엔딩/지역 설명/이벤트 슬라이드의 영문 텍스트를 한국어로 교체
- 이미지 리소스 재패킹이나 별도 컴파일이 필요하지 않습니다.

### 설치

1. 배포 파일의 한국어 슬라이드 이미지를 준비합니다.
2. 게임의 원본 `slide` 폴더에 같은 파일명으로 덮어씁니다.
3. 기존 파일은 필요하면 미리 백업해 두세요.

## 작업 상태

- 슬라이드 이미지 번역: 완료
- 파일명/누락/중복 검사: 완료
- 116장 모두 800×500 JPEG 확인
- 영문 잔상 및 글자 잘림 QA 진행

## 주의

이 저장소는 비공식 팬 한국어화 프로젝트입니다.
원작 게임 및 관련 상표의 권리는 각 권리자에게 있습니다.
